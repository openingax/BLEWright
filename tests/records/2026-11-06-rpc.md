# Mac BLEWright RPC 服务实测

日期：2026-11-06（Asia/Shanghai）。项目：`~/UwantCode/BLEWright`。

## 变更与架构

模拟设备定义、广播、连接状态、GATT 数据、写入效果和通知产生逻辑已移至 `server/`。Android agent 不再导入模拟后端，不包含固定设备地址、服务 UUID 或初始 GATT 值；服务发现结果用于构造原生 Android 对象。

链路：Android 原生 BLE API → Frida agent → Frida 消息通道 → Mac Python 转发器 → 本机 TCP NDJSON RPC → Mac Node.js 模拟后端。Python 转发器不保存 BLE 状态。Android 端仅保留原生对象、同步返回所需的忙/连接状态投影、过滤/回调队列和取消代次。

这是通过 Mac 启动器转发的 RPC，不是 Android 自行建立 TCP 连接。后续可替换转发机制，复用服务协议。

## 环境

- LocalGitPhone / emulator-5554，Android 15 / API 35，arm64，Frida 17.5.1。
- 原测试宿主 `space.nomoloop.blewright.host` 保持不变；正常探针继续只调用原生 BLE API。
- 独立 Mac 服务监听回环地址；开发默认端口 8765；回归程序为每项使用临时端口。
- 不接 ESP32-S3，不涉及真实 BLE 设备或涂鸦配网。

## 验证结果

- `npm run build`：成功。
- Java / DEX 探针编译：成功。
- Python 启动器、转发器、验证脚本语法检查：成功。
- `npm test`：12 / 12，通过 6 项状态测试和 6 项真实 TCP 测试。
- `.venv/bin/python verify_rpc.py --serial emulator-5554`：四项全部通过，退出码 0。

| 行为矩阵项目 | 证据 |
|---|---|
| 原生扫描、FFF0过滤、错误过滤、stop、重复扫描 | rpc-normal 原生探针 PASS |
| 简单 connectGatt / 指定 Handler | rpc-normal，旧/新两轮 PASS |
| 服务发现、重复查询、对象层级与身份 | rpc-normal PASS |
| 新旧写入/读取/通知回调 | rpc-normal，01020304 回读与通知 PASS |
| 重复 disconnect、连接后立即 close | rpc-normal PASS，服务端 connect/close 记录可核对 |
| 本地通知开关与 CCCD 双条件、取消订阅 | TCP 测试 PASS；正常订阅链路也经原生探针验证 |
| 忙、超长写、非法 CCCD、无效属性 | TCP 及状态测试 PASS，未冒充 Android UI 测试 |
| 两客户端状态隔离、退出清理、取消重试 | TCP 测试 PASS |
| 直接停止 Mac 服务 | rpc-disconnect 原生故障探针 PASS |
| 暂停服务进程，连接仍在但不响应 | rpc-timeout 原生故障探针 PASS，ping 超时触发断开 |
| 服务缺失 | rpc-unavailable 启动器非零退出、Connection refused，不启动 App、不本地兜底 |

故障探针实际检查：收到非成功 GATT 断开、扫描失败码 3、isEnabled=false、STATE_OFF、scanner=null、后续 discoverServices 返回 false。未自动重连或重放写入。

```json
{
  "scan.start": 5,
  "scan.stop": 5,
  "connect": 3,
  "discover": 2,
  "notification.set": 4,
  "descriptor.write": 2,
  "write": 2,
  "read": 2,
  "disconnect": 2,
  "close": 3
}
```

服务端异步事件次数：

```json
{
  "advertisement": 3,
  "notification": 4
}
```

验证器同时断言服务收到扫描、连接、发现、读写、CCCD、通知注册、断开、close，且服务产生 01020304 通知，避免只有客户端假成功。

## 实现边界

Mac 端当前为命令行服务，无图形界面。仅测试 API 35、单模拟外设、Central/GATT Client；每个 TCP 会话拥有独立模拟状态。Uwant App / 涂鸦 SDK、iOS、ESP32 与真实无线链路未验证。
