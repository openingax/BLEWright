## 迁移范围

- server → mac/service 与 mac/backends/mock。
- src/agent.js → android/simulatorble；Android 启动器、转发器和 Python 依赖 → android/launcher。
- host/probe/构建工具 → tests/android；test → tests/unit 与 tests/integration；端到端工具 → tests/e2e。
- verification → tests/records，历史内容原样保留。
- ios、firmware 仅增加明确的规划，无未验证实现。
- protocol/constants.json 集中现有版本、默认端口、帧上限、超时和心跳值，未改变数值及 RPC v1 语义。
- 统一根目录 npm 命令；构建产物 → dist/android 与 dist/tests；回归默认输出 → dist/tests/results，不再覆盖归档记录。

共享操作与后端行为不分叉。Android 旧/新 API、普通/指定 Handler、正常/失败路径的差异仍只在平台适配中处理。无业务页面与导航改动。
