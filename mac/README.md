# Mac BLEWright 服务

`service/main.js` 提供命令行入口，`service/server.js` 处理 TCP 帧、会话、请求分发和异步事件，`backends/mock/model.js` 保存模拟设备与连接状态。当前只有 mock 后端，无图形界面和 USB 驱动。

从仓库根目录运行 `npm run serve`。一个 TCP 连接对应一个会话，各会话独立持有模拟状态；断开时清理扫描、连接、订阅及定时任务。服务不引用 Android/iOS 接管实现，不应依赖 Frida。

模拟设备：BLEWright / 02:00:00:00:00:01；服务 FFF0、特征 FFF1、CCCD 2902；初始值 ASCII BLE。支持单 payload 读写，默认 MTU 23，模拟最大 MTU 247；写后读取返回最近值，开启通知与 CCCD 后产生回显。这里是测试后端定义，不属于公共协议。

## 硬件后端接入前的拆分点

`server.js` 目前仍包含 mock 操作调度和服务表；下一步引入硬件时，应把这一块与 mock model 一起收敛到后端实现，服务只负责会话、请求和事件路由。

后端需要提供扫描/停止、连接/断开/关闭、发现、读写特征/描述符、通知注册、MTU、RSSI，以及广播/通知/断连事件。返回值使用公共协议的数据结构，不泄漏 Android/iOS 对象。操作完成、请求接受、设备业务处理成功必须区分。

mock 与未来 S3 后端共用 RPC 入口、会话清理和错误映射；不能为硬件另建一套客户端协议。Mac GUI 后续只调用服务的控制/观察入口。
