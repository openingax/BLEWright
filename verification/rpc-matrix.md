# RPC 迁移行为矩阵（改动前基线）

基线：2026-11-06 API 35 探针已通过。保留新旧 Android 原生 API 行为，模拟设备由 Mac 服务独立持有。

| 输入/动作 | UI/回调及副作用 | 共享或差异 | 验收 |
|---|---|---|---|
| 扫描/FFF0过滤 | 返回 BLEWright；错误过滤不返回 | 共用服务广播，Android 原生 Filter 匹配 | 原生探针 |
| 立即停止/重复扫描 | 停止后无结果；重复报 ALREADY_STARTED | 新旧探针相同 | 原生探针 |
| connectGatt | 返回原生对象，异步 connected | 简单重载默认主线程；显式 Handler 保留 | 原生探针 |
| 发现/重复查询服务 | FFF0/FFF1/CCCD 对象层级与身份稳定 | 共用 RPC 数据建对象 | 原生探针 |
| 新旧读写 | 写入 01020304 后读回相同 | 返回类型与回调适配有差异，后端唯一 | 原生探针 |
| 本地通知 + CCCD | 两条件满足才发通知 | 服务负责订阅和数据，客户端只还原回调 | 原生探针 + TCP 测试 |
| disconnect/close/取消/重试 | 一次断开；旧连接回调无效；新连接可用 | 共享代次与会话隔离 | 原生探针 + TCP 测试 |
| 未连接/忙/超长/非法 CCCD | 拒绝或错误，数据不被污染 | 服务权威状态 | 状态及 TCP 测试 |
| 服务断开/请求超时 | 扫描失败、连接断开、adapter off；不本地兜底 | RPC 新增行为 | 故障探针 + TCP 测试 |
| 服务未启动 | 启动器明确失败，不启动 App | RPC 新增行为 | CLI 负向检查 |
| 两个客户端/会话退出 | 各自值和订阅隔离，退出清理 | 原型仍每会话虚拟设备 | TCP 测试 |

不新增业务页面或导航；所有结果进入 App 原有 callback。测试完成后在 RPC 实测记录中逐项列出结果。
