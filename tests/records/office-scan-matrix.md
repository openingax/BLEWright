# 办公室广播扫描行为矩阵

改动前两个仓库均干净。用户本轮明确禁止连接真实设备；仅允许扫描和广播元数据展示。真实设备不做 GATT 发现、配对、读写或订阅（这些都需要连接）。

| 变体/动作 | 预期 | 验证 |
|---|---|---|
| 原 mock 后端全部原操作 | 行为不变，连接/GATT仅对固定fixture | 原 TCP / iOS / App 回归 |
| ESP32 scan-only hello | 板卡身份与被动扫描能力确认，已有连接时拒绝启动 | 固件 + worker检查 |
| 真实 scan.start/stop | 只发 passive=true 扫描及停止，不发连接命令 | USB命令审计/匿名统计 |
| 重复扫描、10秒扫描周期 | 同一客户端恢复广播刷新，停止/退出不再派发 | 状态/模拟worker测试与实板 |
| 第二个扫描客户端 | 明确 BUSY，不抢占已有会话 | TCP测试 |
| connect/GATT/未知RPC | 服务层拒绝，USB worker白名单再次阻断 | 无硬件假worker负向测试 |
| 16/32/128位UUID/厂商/名称 | 正确解析边界与字节序，残缺广播不崩溃 | 合成数据单元测试 |
| BLEExplorer只读模式 | 连接按钮禁用，直接调用connect也被拒绝 | 单元/UI只读检查 |
| 服务/串口丢失 | 连接不可用，不回退假数据，不自动连接设备 | 定向验证 |

只提交匿名计数与合成测试数据；办公室设备地址、名称和广播明文不写入 Git。真实扫描原始信息仅用于当前本机运行展示。

最终匿名统计与逐项结论见 [验收记录](2026-11-06-office-scan.md)。原 mock TCP/iOS/Android回归通过，真实只读 UI 通过。
