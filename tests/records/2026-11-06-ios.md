# iOS SimulatorBLE / Mac RPC 实测

日期：2026-11-06（Asia/Shanghai）。iPhone Duo，iOS 27.1 Simulator，arm64；Xcode 27.1 / 27A9275。独立宿主 space.nomoloop.blewright.iosprobe，不改 Uwant App。

## 实现

Simulator Debug 专用 Objective-C 库，以环境开关安装 CBCentralManager 方法拦截；CBPeripheral / service / characteristic / descriptor 使用原生类的运行时代理。通过 Network.framework 直接连接既有 Mac TCP RPC，无 Frida，无客户端模拟数据。底层通过与 Android 相同的服务端完成扫描、连接、GATT 操作和通知。

公共 RPC / Mac 服务没有因 iOS 接入而分叉。iOS setNotifyValue 的本地通知注册与 CCCD 合成为串行适配操作，回调仍为标准 CoreBluetooth delegate。

## 构建与验证

- XcodeBuildMCP Simulator Debug 构建通过，最终构建无诊断警告。
- 本地 Swift Package arm64 iOS Simulator Debug 编译通过。
- Swift Package arm64 iOS device Release 编译通过；检查 5 个对象文件，没有 Simulator 专用 BW Objective-C 类。此项不是实际真机运行测试。
- `npm test`：12 项状态/TCP 测试通过。
- Android 既有正常、关闭服务、暂停超时、缺失服务回归再次全部 PASS。
- `npm run verify:ios -- --simulator 36239ADC-8F37-4580-95E7-DECBEDC2F691` 四项全部 PASS，退出码 0。
- 模拟器实际画面显示 PASS，见 [截图](ios-rpc/normal-pass.jpg)。

| 项目 | 实测结果 |
|---|---|
| CBCentralManager 两参数与带 options 初始化 | 主队列/自定义串行队列两轮 PASS |
| 扫描、16 位 UUID 过滤、停止、错误过滤 | PASS，广播来自 Mac 服务 |
| 连接与取消、重复取消、立即取消 | PASS，迟到 connect 结果无成功回调 |
| 服务/特征/描述符发现与父子对象身份 | PASS，均保留 CoreBluetooth 类型 |
| withResponse 写入、读取 | PASS，01020304 一致回读 |

| setNotifyValue、CCCD、订阅/取消订阅 | PASS，服务生成通知；取消后写入不再产生 value 回调 |

| 两轮释放旧 central / peripheral | PASS，修复了释放期间崩溃 |
| 服务直接关闭 | PASS，poweredOff、停止扫描、活动 peripheral 断开 |

## 本轮修复

- 独立测试 App 采用 Scene 生命周期，满足当前 iOS 27.1 SDK 运行要求。
- iOS 27.1 CBPeripheral 析构会移除 delegate 自观察，而通过不可用 init 创建的代理没有该注册。代理构造补齐观察并处理自己的观察事件，使创建/释放配对；主队列到自定义队列第二轮释放回归通过。
- 初始化方法先在 CBCentralManager 上实体化再交换，避免意外修改继承来的超类方法。
- 构建协议头从公共 JSON 自动生成并检查漂移；仅 Simulator Debug 启用拦截。

## 缺口

没有验证 Uwant/涂鸦业务、后台恢复、真实权限、多个 central 共享连接、其它 iOS runtime、真实射频或真机 UI。CoreBluetooth 子类与运行时拦截不是 Apple 支持的扩展机制，首版仅对本次 runtime 做证据声明。描述符读写、RSSI、identifier 查询有实现但不在此探针覆盖；完整广告解析和更多平台 API 尚需补齐。

ESP32-S3 的并行开发是独立验证，见 firmware/verification/2026-11-06.md，不能把它写成 iOS → Mac → S3 已集成。
