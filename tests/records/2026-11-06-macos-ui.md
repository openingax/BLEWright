# BLEWright macOS 视觉改版

## 行为基线与回归矩阵

基线为本次改动前的 desktop/main.swift，结合 2026-11-06-macos-manager.md。只改 AppKit 展示与资源打包；ControlClient、管理请求、菜单操作、文件导入与确认流程保持原实现。共享渲染覆盖 scan-only / controlled，两模式只保留已有的身份导入差异。

| 输入与状态 | UI / 动作 | 副作用、导航基线 | 本次验证 |
|---|---|---|---|
| 两模式 × waiting / starting / ready / stopped / error / flashing / restarting | 显示相应状态、模式、固件、地址和绑定设备 | 一秒轮询；只刷新显示 | 两模式 × 七状态 × 深浅色共 28 组真实 AppKit 渲染断言通过 |
| 两模式 × busy | 操作按钮、开发板和模式禁用 | 不改变请求和维护流程 | 渲染断言通过 |
| 两模式 × USB 有 / 无 | 重启菜单可用性跟随设备 | 保留枚举、选择逻辑 | 渲染断言通过 |
| 两模式 × 日志有 / 无 × 错误有 / 无 | 日志、空提示与错误显示 | 日志仍可选择复制、更新滚到末尾 | 渲染断言通过 |
| 未应用的模式和 USB 选择 | 收到下一次状态，USB 路径变化 | 保留用户选择，不被轮询覆盖 | 渲染断言通过 |

| 重启 / 刷写 | 确认 → 取消 | 不重启、不刷写，服务保持 ready | 原生窗口实际操作通过 |
| 已安装后台运行 | 新界面连接 | 显示真实 S3 ready、固件与日志 | 最终签名 App 实际运行通过 |

| 启动 / 停止 / 接受配置 / 确认维护 | 原请求和确认逻辑 | 后台与硬件行为保持原实现 | 既有 33 项 Node + 21 项 Python 测试通过；本次没有再次执行实际硬件写入、重启或刷写 |
