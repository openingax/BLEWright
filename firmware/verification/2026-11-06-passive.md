# ESP32-S3 仅被动扫描验收

日期：2026-11-06（Asia/Shanghai）。本轮用户允许发现真实广播，明确禁止连接真实设备；遵守该限制，没有启动自建 Mac 外设，也没有运行旧 verify_hardware.py。

## 最小变更

- scan.start 支持严格 Bool 的 params.passive；省略时保持历史主动扫描。
- 参数 true 直接设置 NimBLE ble_gap_disc_params.passive=1；响应回显实际 passive。
- hello 新增 connected、connecting、scanning 和 passiveScanSupported，只查询板上状态，不发起连接。
- 固件版本为 blewright-s3/0.2。
- 新增 verify_passive_scan.py，只包含 hello / ping / scan.start / scan.stop 允许列表；实际本轮发送 hello、scan.start(passive=true)、scan.stop。

## 验证

- ESP-IDF v5.5.1 编译通过，普通烧录 /dev/cu.usbmodem2021401 成功，esptool 校验写入哈希通过。
- 没有改 eFuse、没有擦整片 Flash，原始 16MB Flash 备份保持原处。
- 新的工具测试 4 / 4 通过：只发送被动扫描命令且输出聚合结果、拒绝已连接板卡、拒绝不支持 passive 的旧固件、没有广播不假报成功。
- 10 秒实际被动监听通过；只输出 [聚合计数](passive-scan-summary.json)，没有保存或提交办公室设备名称、地址和广播明文。
- 前后 connected=false、连接 generation 不变、scanning 已停止、丢帧 0。没有发送 connect、cancel、disconnect、read、write 或订阅。
- 串口已关闭释放，供 Mac scan-only 后端后续验收。

观察到 277 个广播帧和 127 个临时地址身份；地址可能轮换，该数量不代表物理设备数。主动扫描兼容路径本轮未在办公室执行，仅保留原代码默认值。

## 可复跑命令

```sh
source "$HOME/esp/esp-idf/export.sh"
python firmware/tests/test_passive_scan.py
python firmware/tools/verify_passive_scan.py --port /dev/cu.usbmodem2021401 --seconds 10
```
